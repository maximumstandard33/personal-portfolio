Career Curator

A Personal Career Management Platform.

Project Overview

Career Curator is a web application designed to help users organize their job applications and track their learning progress.

Key Features

  • Career Dashboard with KPI cards
  • Job Application Tracking
  • Study Session Logging
  • Resume Draft Editor
  • Interview Preparation Workspace

Technologies Used

  • HTML
  • CSS
  • JavaScript
